Your first settlement in four steps.

  1. 01

    Request access

    Approved requests get an enclave key scoped to hardware, usually within a business day.

  2. 02

    Install a client

    The MCP server for agent runtimes, or the Rust SDK for devices and edge services.

  3. 03

    Delegate and settle

    Mint a session key with a scope and expiry, then clear a payment with it.

  4. 04

    Verify the receipt

    Check the attestation and, for physical actions, the C2PA checkpoint before release.

import { AgentEscrow } from "@arisma-network/agent-escrow-mcp";

const escrow = await AgentEscrow.connect({ enclave: "tee:sev-snp" });
const session = await escrow.delegate({ scope: ["settle"], ttl: 900 });

const receipt = await session.settle({
  to: "drone:fleet-04", asset: "usdc", amount: "0.14",
});
// receipt.finalityMs -> 1400
use arisma_edge_enclave::{Enclave, Erc7702Session, Scope, Asset};

let enclave = Enclave::attach("tee:sev-snp")?;
let session = enclave.delegate(Erc7702Session {
    scope: Scope::Settle, ttl: 900,
})?.attest()?;

let receipt = session
    .settle("drone:fleet-04", Asset::Usdc, cents(14))
    .await?;

Agent Escrow MCP

A Model Context Protocol server that gives any MCP client four tools: delegate, settle, attest, and verify. Agents hold funds in escrow, negotiate rates, and pay for finished tasks without custom plumbing.

Four calls cover the whole protocol.

The same operations exist as MCP tools and as SDK methods. Each one maps to a step on the settlement path.

CallWhat it doesYou get backLearn it
delegateMints a scoped ERC-7702 session key inside the enclave, with an expiry.A session handle bound to hardwareTrust model
settleClears a stablecoin microsettlement between two actors.A deterministic receipt with finality timeSettlement
attestProduces a zero knowledge proof that a policy holds.A proof a gate can check without the inputsAttestation
verifyChecks a C2PA checkpoint and any human gate before release.Release, or a hold with the reasonAttestation
