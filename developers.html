import { Arisma } from "@arisma-network/agent-mcp";

const arisma = await Arisma.connect({ runtime: "sev-snp" });
const session = await arisma.delegate({ scope: ["settle"], ttl: 900 });

const receipt = await session.settle({
  to: "drone:fleet-04", asset: "usdc", amount: "0.14",
});
// receipt.confirmedMs -> ~1400
use arisma_edge_enclave::{Enclave, Erc7702Session, Scope, Asset};

let enclave = Enclave::attach("sev-snp")?;
let session = enclave.delegate(Erc7702Session {
    scope: Scope::Settle, ttl: 900,
})?.attest()?;

let receipt = session
    .settle("drone:fleet-04", Asset::Usdc, cents(14))
    .await?;

For LLM agents

Arisma Agent MCP

A Model Context Protocol server that gives any MCP client four tools: delegate, settle, attest, and verify. Agents spend from bounded mandates, agree on rates, and pay for finished tasks without custom plumbing.

Four calls cover the whole protocol.

The same operations exist as MCP tools and as SDK methods. Each one maps to a step on the settlement path.

CallWhat it doesYou get backLearn it
delegateCreates a mandate: a scoped, expiring permission on an ERC-7702 account, signed by a hardware-held keyA mandate handleTrust model
settlePays under a mandate, singly or netted into a batchA deterministic receipt with confirmation timeSettlement
attestAttaches signed evidence to a payment; policy proofs when they shipEvidence the gate can checkAttestation
verifyChecks evidence, and any human approval, before releaseRelease, or a hold with the reasonAttestation
