Create a mandate and pay

Connect, create a mandate with a scope and an expiry, and pay under it. The receipt is deterministic and reports its confirmation time.

import { Arisma } from "@arisma-network/agent-mcp";

const arisma = await Arisma.connect({ runtime: "sev-snp" });
const session = await arisma.delegate({ scope: ["settle"], ttl: 900 });
const receipt = await session.settle({
  to: "drone:fleet-04", asset: "usdc", amount: "0.14",
});
// receipt.confirmedMs -> ~1400

Verify the receipt

Every receipt carries its evidence. Check the signatures and, for high-stakes physical actions, the human approval before releasing value or machinery.
