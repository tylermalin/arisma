Delegate and settle

Connect to the enclave, delegate a scoped session key, and clear a settlement. The receipt returns deterministic finality.

import { AgentEscrow } from "@arisma-network/agent-escrow-mcp";

const escrow = await AgentEscrow.connect({ enclave: "tee:sev-snp" });
const session = await escrow.delegate({ scope: ["settle"], ttl: 900 });
const receipt = await session.settle({
  to: "drone:fleet-04", asset: "usdc", amount: "0.14",
});
// receipt.finalityMs -> 1400

Verify the receipt

Every receipt carries its proof. Check the zk-TEE attestation and, for physical actions, the C2PA checkpoint before releasing value or machinery.
