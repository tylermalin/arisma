Developers

Edge Enclave SDK.

Enclave keys scoped to hardware and the Rust integration.

developers / sdk

The Edge Enclave SDK keeps mandate keys in hardware: SEV-SNP or TDX for cloud services, the X1's TPM for devices. An agent or machine can prove what it may do without ever holding the owner key. It is the Rust foundation under the MCP server.

Install

Install commands appear here the day the packages publish to npm and crates.io. Approved teams get early builds now through testnet access.

Delegate, attest, settle

use arisma_edge_enclave::{Enclave, Erc7702Session, Scope, Asset};

let enclave = Enclave::attach("sev-snp")?;
let session = enclave.delegate(Erc7702Session {
    scope: Scope::Settle, ttl: 900,
})?.attest()?;

let receipt = session.settle("drone:fleet-04", Asset::Usdc, cents(14)).await?;

Capabilities

  • ›Hardware-held keys: mandate keys stay in SEV-SNP or TDX for cloud services, or the X1's TPM for devices.
  • ›Attestation: a VM attestation report or a TPM quote is checked before a mandate is issued.
  • ›Policy checks: the gate checks signed readings against the policy; policy proofs are on the roadmap.
  • ›Signed evidence: tie a payment to a recorded event, with C2PA manifests for media captures.
