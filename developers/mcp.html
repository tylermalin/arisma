Developers

Arisma Agent MCP.

Model Context Protocol integration so agents can spend from bounded mandates and pay for tasks.

developers / mcp

The Arisma Agent MCP server exposes Arisma mandates, settlement, and evidence as Model Context Protocol tools, so any agent runtime that speaks MCP can spend from a bounded mandate, agree on rates, and pay for finished tasks without custom plumbing.

Install

Install commands appear here the day the packages publish to npm and crates.io. Approved teams get early builds now through testnet access.

Configure

Add the server to your MCP client configuration.

{
  "mcpServers": {
    "arisma": {
      "command": "npx",
      "args": ["@arisma-network/agent-mcp"],
      "env": { "ARISMA_ENCLAVE": "tee:sev-snp" }
    }
  }
}

Tools

  • ›delegate: create a mandate, a scoped, expiring permission on an ERC-7702 account, signed by a hardware-held key.
  • ›settle: pay under a mandate, singly or netted into a batch.
  • ›attest: attach signed evidence to a payment; policy proofs when they ship.
  • ›verify: check evidence, and any human approval, before release.
