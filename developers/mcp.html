Agent-Escrow MCP.

Model Context Protocol integration so agents can hold funds and settle tasks.

developers / mcp

The agent-escrow MCP server exposes Arisma clearing and attestation as Model Context Protocol tools, so any MCP-aware agent runtime can hold funds, negotiate rates, and settle tasks without custom plumbing.

Install

npx @arisma-network/agent-escrow-mcp

Configure

Add the server to your MCP client configuration.

{
  "mcpServers": {
    "arisma-escrow": {
      "command": "npx",
      "args": ["@arisma-network/agent-escrow-mcp"],
      "env": { "ARISMA_ENCLAVE": "tee:sev-snp" }
    }
  }
}

Tools

  • ›delegate: mint a scoped ERC-7702 session key inside the enclave.
  • ›settle: clear a stablecoin micro-settlement between machines.
  • ›attest: produce a zero-knowledge policy proof for a gate.
  • ›verify: check a C2PA checkpoint before release.
