Protocol primitives & payloads.

Readable, composable building blocks for agentic infrastructure.

platform / primitives

Every layer of Arisma is expressed as a clean, verifiable payload. Toggle between JSON envelopes and Rust calls to see what your agent runtime sends and receives.

Three primitives.

Mandate

A scoped, expiring permission to spend, signed by a key held in hardware.

// mandate
{
  "mandate": "0x7a…c4",
  "account": "erc-7702",
  "permission": "session",
  "signer": { "curve": "p-256", "held_in": "tpm" },
  "scope": ["pay"],
  "cap_usdc": "21.00",
  "rate_per_min": 10,
  "expires_s": 900
}
let key = enclave
  .delegate(Erc7702Session {
    scope: Scope::Pay,
    ttl: 900,
  })?
  .attest()?;

Settlement

A payment between two machines, settled in USDC under a mandate.

// settlement
{
  "from": "agent:dispatch",
  "to": "drone:fleet-04",
  "asset": "usdc",
  "amount": "0.14",
  "chain": "base-sepolia",
  "mode": "single",
  "confirmed_ms": 1400
}
let rcpt = settlement
  .settle(Transfer {
    asset: Asset::Usdc,
    amount: cents(14),
  })
  .await?;  // ~1.4s confirmation, Base Sepolia

Evidence and release

Signed evidence for the event, and a release a person can hold.

// release gate, drone capture
{
  "policy": "field-inspect",
  "evidence": "sha256:9f…a1c",
  "media_manifest": "c2pa",
  "review": "human",
  "on_hold": false
}
let gate = verify
  .prove(policy)?
  .checkpoint(Evidence::hash(frame))
  .require_human(high_stakes);
