02 / primitives

Identity & delegation

A scoped session key, signed in the enclave, bounded by policy.

// delegation envelope
{
  "standard": "erc-7702",
  "session": "0x7a…c4",
  "enclave": "tee:sev-snp",
  "scope": ["settle", "attest"],
  "expires": 900
}
let key = enclave
  .delegate(Erc7702Session {
    scope: Scope::Settle,
    ttl: 900,
  })?
  .attest()?;

M2M clearinghouse

A settlement request between two machines, cleared deterministically in stablecoin.

// settlement
{
  "from": "agent:dispatch",
  "to": "drone:fleet-04",
  "asset": "usdc",
  "amount": "0.14",
  "finality_ms": 1400
}
let rcpt = clearing
  .settle(Transfer {
    asset: Asset::Usdc,
    amount: cents(14),
  })
  .await?;  // 1.4s

Human-in-the-loop

A zk policy proof with a C2PA checkpoint a reviewer can hold.

// verification gate
{
  "policy": "zk:field-inspect",
  "c2pa": "0x9f…a1c",
  "review": "human",
  "on_hold": false
}
let gate = verify
  .attest_zk(policy)?
  .checkpoint(C2pa::hash(frame))
  .require_human(high_stakes);
