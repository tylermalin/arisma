Three digital twins, running around the clock.

Simulated projects that behave like live deployments. Every event follows the same path: mandate, evidence, settle, release, receipt.

Simulated

These are digital twins, not real machines or payments. Each twin runs on a seeded clock, so the stream never stops and every visitor sees the same events. Amounts are illustrative. Receipts are real SHA-256 digests of each payment's inputs, so you can recompute them.

        Stream

        Connecting to the stream.

          Read the stream yourself.

          The same feed is a public JSON endpoint. Ask for any moment in the past and you get the same events every time, which is what makes each receipt checkable.

          # the last 60 seconds
curl https://www.arisma.network/api/stream

# 5 minutes of the warehouse, ending at a fixed time
curl "https://www.arisma.network/api/stream?twin=warehouse&window=300&at=1793736000000"
          at
          End of the window in milliseconds. Past windows never change and are cached for a day.
          window
          Seconds to return, 1 to 900. Defaults to 60.
          twin
          drone-dock, warehouse, or ev-depot.
          events[]
          Each event has a type (telemetry, evidence, payment, settlement, release, hold, rejected), the actor, its mandate, and for settlements a receipt and confirmation time.
